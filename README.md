# 📈 Stock Analysis Dashboard – Infosys Stocks

## Project Overview

This project presents an interactive Stock Analysis Dashboard developed using Power BI. The dashboard provides comprehensive insights into historical stock market performance by analyzing stock prices, trading volumes, and key market trends. The objective is to help investors and analysts make data-driven decisions through effective data visualization.

## Problem Statement

Stock market data contains valuable information that can help investors understand price movements and market behavior. The goal of this project is to transform raw stock data into meaningful visual insights that support trend analysis and performance evaluation.

## Dataset

The dataset contains historical stock market information, including:

* Date
* Open Price
* Close Price
* High Price
* Low Price
* Trading Volume
* Daily Price Movements

## Project Workflow

1. Data Collection
2. Data Cleaning and Preparation
3. Data Modeling in Power BI
4. KPI Creation using DAX
5. Interactive Dashboard Development
6. Trend and Performance Analysis
7. Data Visualization and Reporting

## Dashboard Features

### Key Performance Indicators (KPIs)

* Highest Stock Price
* Lowest Stock Price
* Average Stock Price
* Total Trading Volume

### Visualizations

* Line Chart for Stock Price Trends
* Clustered Column Chart for Volume Analysis
* Ribbon Chart for Trend Comparison
* Pie Chart for Distribution Analysis
* Clustered Bar Chart for Performance Metrics
* Interactive Date Slicer for Dynamic Filtering

## Technologies Used

* Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization

## Key Insights

* Analyzed historical stock price trends over time.
* Identified periods of high and low market activity.
* Compared stock performance across different time periods.
* Evaluated trading volume patterns and market behavior.

## Conclusion

The Power BI dashboard successfully transforms stock market data into meaningful visual insights. Through interactive charts and KPI tracking, users can efficiently monitor stock performance, identify trends, and make informed decisions based on historical market data.
